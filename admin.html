Falta conectar la base de datos (gratis). Los cambios no se pueden guardar hasta que la conectes en Vercel:
  1. En Vercel → tu proyecto → pestaña Storage → Create Database.
  2. Elige Upstash for Redis (plan Free), región cercana (por ejemplo Washington o São Paulo) y dale Create.
  3. Conéctala a este proyecto (marca Production y Preview) y luego ve a Deployments → ⋯ → Redeploy. Listo.
